一句话定位

传统 AI 批改是「黑盒」，给分不给理由、还会凭空引用原文。彼此_Autograder 用 证据锚点 + 反查防幻觉 让每一次打分都可溯源，并打通 教师批阅 与 学生自查 两端，形成「预自查 → 修改 → 提交 → 批阅/打回 → 再改」的完整闭环。

创新点（评审核心关注）

1可解释评分 · 证据可溯源

每个评分点都锚定到报告原文的「证据块」（chunkId + 原文引用），点击可回跳并高亮原文。给分必有出处，从根上解决「黑盒打分」不可信的问题。

2证据反查防幻觉（机制级）

大模型给出的「原文引用」必须通过子串校验——不是报告里的原句就拒绝采纳，退回按章节语义重新定位。用工程手段堵住 LLM 幻觉，而非依赖提示词祈祷。

3一套内核、两种人格

同一套评分引擎，教师端输出「严格定分 + 证据链」，学生端输出「建设性建议 + 定位」，语气与结构随角色切换。技术上一石二鸟，产品上完整闭环。

4批改习惯记忆（Agent 记忆）

教师手动改分后，系统记住「某评分点扣分标准」，下次自动按此执行。这是「智能体记忆 + 反馈」最直观的具象化，越用越懂老师的标准。

5确定式检索 + LLM 判定

证据检索由程序按章节语义精准定位，大模型只负责「理解与打分」。既保证证据准确（不牛头不对马嘴），又显著提速、规避了模型自由工具调用的不稳定。

6师生双端闭环

预自查 → 修改 → 提交 → 批阅/打回 → 再改，形成真实的教学迭代闭环，而非单向的「上传即出分」。

解决的痛点

1

批改量大、重复劳动—— 高校实验报告动辄一个班几十份，逐份逐点评分耗时巨大。

2

传统 AI 批改是黑盒—— 给分不给理由，教师不敢信、学生不服气，只能当玩具。

3

AI 幻觉—— 大模型会凭空引用报告里根本不存在的原文，结论经不起查证。

4

学生缺可操作反馈—— 拿到分数不知道「错在哪、怎么改」，无法形成改进。

5

批量批改缺个性化—— 千篇一律的模板评语，无法针对每个学生的具体问题。

优缺点自评

优势

  • 可解释性强：证据锚点 + 反查防幻觉是核心竞争力
  • 双端闭环完整：师生两端 + 打回迭代，产品形态完整
  • 真实大模型接入（混元 hy4-preview），非 mock 演示
  • 视觉精致：ChatGPT / Vercel / Apple 风格，高级感强
  • 演示稳妥：纯前端状态机，不依赖后端数据库

局限 / 待改进

  • 数据层为纯前端内存 + localStorage，无真实数据库与多用户持久化
  • 登录是「角色选择」，无真实鉴权
  • 单次评分约 20 秒，受大模型推理速度限制
  • 移动端（<1024px）响应式不完善
  • 学生端「改完再查看提升」的迭代闭环尚未完整实现
  • 内置细则目前仅「操作系统实验二」，扩展其他实验需手动配置
