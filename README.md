# 彼此_Autograder · 可解释的 AI 助教

面向高校计算机实验报告的「师生双端闭环」自动评分系统。

- 教师端：AI 评阅（证据可溯源）、班级看板、待批阅、一键批阅 / 打回
- 学生端：AI 预自查（分优先级建议）、提交作业、被打回后重新修改
- 核心：**证据锚点 + 反查防幻觉**，每一次打分都可溯源到报告原文

## 一键启动（Windows）

1. 解压本压缩包到任意目录
2. 双击 **「一键启动.bat」**
3. 首次运行会自动安装依赖（约 2-3 分钟，需联网）
4. 浏览器自动打开 http://localhost:3000

> 环境要求：Node.js v18 或以上（未安装则到 https://nodejs.org/ 下载 LTS 版）

## 录屏注意事项

- 保持黑色命令行窗口开启（关闭即停止服务）
- AI 评分需联网（已内置腾讯混元 API Key，无需配置）
- 端口固定为 3000

## 建议的演示流程（录屏顺序）

**教师端**
1. 登录页点「我是教师」
2. 「评阅」页 → 拖入一份实验报告（可用根目录 `江水平平仄-操作系统实验二.txt`）→ 观察 AI 逐点评分 + 证据可溯源
3. 点「定位原文」看高亮涟漪、点「评分依据」看扣分原因
4. 「工作台」→ 班级看板（KPI + AI 智能总结）
5. 「待批阅」标签 → 点学生名看报告 → 「一键批阅」出真实分数 / 「打回重交」
6. 手动改分 → 观察「已记住您的偏好」提示

**学生端**
7. 右上「退出登录」→ 点「我是学生」
8. 加入班级（邀请码 `CS101`）
9. 拖入报告 → 「AI 预自查」→ 查看分级建议（严重/建议/优化）+ 一键采纳 + 评分依据定位
10. 「提交给教师批阅」

**双端闭环**
11. 切回教师端 → 待批阅看到该学生作业 → 打回
12. 切回学生端 → 看到「被打回 + 整改意见」→ 重新修改

Next.js 16 · TypeScript · Tailwind CSS · 腾讯混元大模型（hy4-preview）
